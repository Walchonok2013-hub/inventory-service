# Менеджер домашних запасов (Inventory Service)

Backend-сервис для управления домашними запасами продуктов и бытовых товаров. Реализован на стеке: **Python 3.11+, FastAPI, SQLAlchemy, PostgreSQL, Celery + Redis**.

## Ключевые особенности реализации

*   **Учет партий:** Один товар может иметь несколько партий с разными сроками годности и местами хранения.
*   **Стратегии списания:** Поддержка стратегий `expires_first`, `oldest_first` и ручного выбора партии.
*   **Конкурентный доступ:** Защита от двойного списания через `SELECT ... FOR UPDATE` и транзакции БД.
*   **Идемпотентность:** Все мутирующие запросы поддерживают заголовок `Idempotency-Key`.
*   **Прогнозирование:** Расчет среднего дневного расхода и прогнозируемой даты окончания товара.
*   **Фоновые задачи:** Ежедневный пересчет статусов, генерация рекомендаций и уведомлений (Celery Beat).

## Стек технологий

| Компонент | Технология | Примечание |
| :--- | :--- | :--- |
| **Web Framework** | FastAPI | Высокая производительность, автоматическая документация |
| **ORM** | SQLAlchemy (Async) | Работа с базой данных |
| **Database** | PostgreSQL | Хранение данных, транзакционность |
| **Cache / Broker** | Redis | Хранение временных данных, брокер для Celery |
| **Background Jobs** | Celery + Beat | Фоновые задачи и расписание |
| **Auth** | JWT (HS256) | Регистрация, логин, защита эндпоинтов |
| **Testing** | pytest + httpx | Покрытие бизнес-логики и API |
| **Migrations** | Alembic | Управление схемой БД |
| **Containerization** | Docker Compose | Локальный запуск всех сервисов |
